# OEM battery optimization

Aggressive OEMs can kill Latch’s background monitor. After install:

1. Disable **battery optimization** for Latch (Settings → Apps → Latch → Battery → Unrestricted).
2. Allow **autostart** where the OEM exposes it (Xiaomi, Oppo, Vivo, Huawei).
3. Lock Latch in **Recents** if the skin supports “lock app”.
4. Optional: enable the **Pause tile** only when you intentionally stop automation.

Latch does not use the network. Background work is local rule evaluation only.

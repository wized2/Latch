# Latch recipe packs

Import any JSON file from the app (**Import rules**). Both the recipe wrapper and a bare rules array are accepted.

| File | Idea |
|------|------|
| `battery_saver.json` | Dim brightness when battery is low |
| `sleep_focus.json` | Night / focus style rule |
| `work_wifi_silent.json` | Silent ringer on a work SSID |
| `headphones_music.json` | Open music app on headphone connect |
| `commute_bluetooth_music.json` | Raise media volume and open music on Bluetooth connect |
| `charging_notify.json` | Notify when charging starts |
| `night_dnd.json` | Silent between 22:00 and 07:00 |
| `bedtime_winddown.json` | Dim screen and switch ringer to vibrate at bedtime |
| `boot_welcome.json` | Notify after boot |
| `car_bluetooth.json` | Vibrate ringer when a Bluetooth device connects (fires for any device: refine before use) |

Edit SSID, packages, and times before relying on a recipe.
